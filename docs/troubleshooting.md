# Troubleshooting

| Symptom                                                      | Cause and fix                                                                                                                                                                                |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `APPROVAL_INVALIDATED: the test plan changed after approval` | The plan (or a default it depends on) changed after approval. Run `preview` and `approve` again.                                                                                             |
| `INTEGRITY_MISMATCH: ... was modified`                       | The execution plan, a work packet or the approval record was edited after generation. Regenerate; never hand-edit approved files.                                                            |
| `RISK_APPROVAL_REQUIRED`                                     | The plan has risky steps. Review them, then approve interactively (type the `accept-risk ...` phrase) or pass `--accept-risk --risk-plan-hash <hash>`.                                       |
| Validation error `blocked by safety policy`                  | A step looks like a risky action (delete, purchase, sign up, ...). Remove it, or enable the category in `safety` and use risk approval.                                                      |
| `safety.allowExternalNavigation` error                       | External navigation cannot be enabled. Add the needed host to `target.allowedDomains`.                                                                                                       |
| Packet BLOCKED `navigation to ... blocked`                   | A step navigated (or linked) outside the allowed domains; the guard aborted the request.                                                                                                     |
| Packet BLOCKED `replacement_agent_unavailable`               | A lifecycle limit was reached (e.g. `maxActionsPerAgentInstance`). Milestone 1 persists the checkpoint and handoff and stops. Raise the limit or wait for Milestone 3 automatic replacement. |
| Packet BLOCKED `handoff_limit_exceeded`                      | Rotations reached `maxHandoffsPerWorkPacket`. Raise the cap or split the scenario.                                                                                                           |
| Packet BLOCKED `checkpoint persistence failed`               | The artifact directory is not writable (disk full, permissions). Free space or change `--output`.                                                                                            |
| `test data could not be resolved: key (env VAR)`             | A `fromEnv` test value is not set in the environment.                                                                                                                                        |
| Locator timeouts                                             | Prefer `role`+`name`, `label` or `testId` locators; raise `browser.actionTimeoutMs` or the step's `timeoutMs`.                                                                               |
| Browser fails to launch                                      | Run `pnpm exec playwright install chromium`, or set `BROWSERSWARM_CHROMIUM_EXECUTABLE`.                                                                                                      |
| OpenCode command fails                                       | Adapt `argsTemplate` to your OpenCode version (`opencode --help`); see [opencode.md](opencode.md).                                                                                           |
| Compiled plan marked `needsReview`                           | The prompt had lines the compiler could not understand; they are listed as ambiguities. Edit the plan or rephrase using the grammar in [test-plan-format.md](test-plan-format.md).           |
